# DROVE Brand Assets

Canonical brand files for the DROVE rebrand (Phase 3.5, Issue #36) and all
marketing/UI work. Full usage rules (colors, spacing, typography) live in
`Drove_Brand_Guidelines.pdf` (kept in the Perplexity Space files; ask Kevin
if you need it).

| File | Use |
| --- | --- |
| `drove_primary_horizontal_3000w.jpg` | Primary horizontal lockup — bison mark + DROVE wordmark + tagline "Keep the herd moving." |
| `hero_bison_2000w.jpg` | Standalone geometric bison mark — hero/large-format use. |

Brand ethos (decision root, per Kevin, 2026-07-17): DROVE is a STRONG brand.
Code, UI, and UX are held to a first-class bar — nothing ships as "just good
enough." The geometric, forward-charging bison is the design language the
product should speak.

> Note: JPGs have white backgrounds. Before Phase 3.5 UI work, add
> transparent-background PNG/SVG exports of the mark and lockup to this
> folder (needed for headers, dark surfaces, and app icons).
